# 洋書トーク 販売までのシミュレーション

2026年10月時点の料金での試算です（$1 = ¥150 で計算）。実際の金額は、お試し期間の OpenAI の請求で必ず確かめてください。

## 1人あたりの月の原価（変動費）

| 内訳 | 平均的な人（トーク30分・辞書30回） | 上限まで使う人（トーク60分・AI 200回） |
|---|---|---|
| GPT-Live（$0.05/分） | $1.50 | $3.00 |
| トーク中の裏方 AI（ディスプレイ表示・単語保存） | 約 $1.00 | 約 $2.00 |
| トーク後のフィードバック | 約 $0.30 | 約 $0.50 |
| 辞書・質問チャット（1回 約 $0.03） | 約 $1.10 | 約 $6.00 |
| **合計** | **約 $3.9（約 ¥590）** | **約 $11（約 ¥1,650）** |

- 裏方 AI（gpt-5.5：入力 $5／出力 $30 per 100万トークン）は、トーク時間とは別に請求されます。
- 料金の目安：**月 ¥1,980（トーク60分）** なら、上限まで使う人がいても赤字になりません。¥1,480 にすると、平均的な人では利益が出ますが、上限まで使う人では赤字になります。

## 段階ごとにやること

### 段階0：仲間内のお試し（〜30人）※今ここ

**やること**
- Supabase（無料プラン）をセットアップし、招待コードを仲間に配る（`supabase/README.md`）
- OpenAI のプロジェクトに **月の利用上限（Budget）** を設定する（例：$100）
- **1人あたりの実際の原価**を OpenAI の Usage 画面で記録する（これが料金設定の根拠になります）
- 使いにくい点・欲しい機能を集める

**費用**
- 固定費：**¥0**（Supabase・Cloudflare・GitHub Pages・Pixabay すべて無料枠）
- 変動費：30人 × 約¥590 ＝ **約¥18,000／月**（全員が上限まで使うと約¥50,000）
- 売上はないので、全額自己負担です

**注意**
- 7日間誰も使わないと Supabase が一時停止することがあります（警告メールが来たらダッシュボードを開く）
- 確認メールを送らない設定なので、パスワードを忘れた人は管理画面から対応します

### 段階1：販売開始（〜100人）

**始める前にやること**
| やること | 理由 | 費用 |
|---|---|---|
| Supabase を **Pro** にする | 一時停止がなくなり、毎日のバックアップが付く | $25／月 |
| **独自ドメイン**を取る（例：yosho-talk.jp） | メール送信の設定と、信頼感のため | 約 ¥1,500〜3,000／年 |
| **メール送信（SMTP）** を設定し、確認メールをオンにする | 偽の登録の防止、パスワード再設定のため（例：Resend 無料枠 月3,000通） | ¥0 |

| 特定商取引法の表記・利用規約・プライバシーポリシー | 販売に必須 | ¥0（自作）〜 数万円（専門家に確認） |
| アバター画像・書影・発音音声のライセンス確認 | 商用利用の可否 | — |
| エラーの見張り（Sentry 無料枠）、問い合わせフォーム | 有料サービスの対応品質 | ¥0 |
| 紹介ページ、YouTube 概要欄からの導線 | 集客 | ¥0 |

### 段階2：伸びてきたら（〜1,000人）

**このころ必要になること**
| きっかけ（見る場所） | やること | 費用の変化 |
|---|---|---|
| Supabase の CPU 警告・遅さ（Supabase の Reports 画面） | コンピュートを Micro → Small に上げる | ＋$15／月 |
| 送るメールが月3,000通を超える | メール送信を有料プランにする | ＋$20／月 |
| OpenAI のエラー「429（混雑）」が出る | OpenAI の利用ティアを上げる（支払い実績で自動的に上がる）／上限の引き上げを申請 | — |
| AI の原価が売上の30%を超える | 辞書の結果をみんなで共有して保存する（同じ単語は2回目から無料に） | AI の原価が大きく下がる |
| 問い合わせが増える | よくある質問ページ、問い合わせ管理 | — |
| 年間の売上が1,000万円を超えそう | 税理士に相談（消費税・インボイス・法人化） | 顧問料など |

**1,000人のときの月の収支（目安）**
- 売上 ¥1,980,000 − Stripe ¥71,000 − 固定費 約¥13,000 − 変動費 約¥590,000 ＝ **利益 約 ¥1,300,000**
- Cloudflare の中継サーバーは、まだ無料枠（1日10万回）で足ります

### 段階3：爆発的に増えたら（〜10,000人）

| やること | 理由 |
|---|---|
| OpenAI と大口の契約・上限の相談 | 原価の大半が OpenAI（約 ¥590万／月）。混雑で使えなくなるのが一番のリスク |
| 安いモデルへの切り替え（辞書など） | 原価の削減 |
| 料金プランの見直し（追加の分数を買えるなど） | たくさん使う人の原価を回収する |
| Supabase のコンピュートを上げ、時点復元バックアップ（PITR）を付ける | 安定性とデータ保護（約 ¥30,000〜50,000／月） |
| Cloudflare Workers を有料プランにする | 1日10万回を超えるため（$5／月〜） |
| トーク時間の数え方を厳しくする | 今はアプリからの報告で数えているので、不正な使い方への対策を強める |
| 法人化・会計・サポート体制 | 月の売上が約2,000万円規模 |

## 急に増えたときに一番気をつけること

1. **OpenAI の利用上限（Budget）**：上限に達すると全員のトークが止まります。50%・80% で通知を受け取り、早めに上限を上げます。
2. **OpenAI の混雑（429 エラー）**：利用ティアの引き上げには時間がかかることがあるので、伸び始めたら早めに相談します。
3. **Supabase の無料プラン**：販売開始と同時に Pro にしておけば、急増しても止まりません（Pro への切り替えはボタン一つ、作り直し不要）。
4. **新規登録の受付**：対応が追いつかないときは、招待コード制のまま人数を絞ることもできます。
